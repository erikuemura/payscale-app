# ADR 0001 — SDD em Markdown e contexto para Codex

Status: adotado para a organização local solicitada. Data: 2026-11-03.

## Contexto

O repositório tinha README genérico, AGENTS.md com orientação Next.js e CLAUDE.md apontando para AGENTS.md. Faltavam especificações de produto e registro explícito de limitações demonstrativas.

## Decisão

Usar AGENTS.md como instrução de entrada do Codex, specs/ como fonte de requisitos e docs/decisions/ para decisões. Cada mudança relevante terá spec, plano, tarefas e evidências. Manter CLAUDE.md como ponte opcional para a mesma fonte e preservar .claude/launch.json como compatibilidade histórica; não são necessários ao Codex.

Não adicionar framework SDD nem configurações de modelo, permissões ou serviços globais. A convenção é portátil e revisável em Git.

## Consequências

O contexto acompanha o código, mas precisa ser atualizado a cada mudança. Documentar comportamento existente não comprova sua correção. Sessões privadas e configurações externas exigem transferência separada quando houver necessidade concreta.
